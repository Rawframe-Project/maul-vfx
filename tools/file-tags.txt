# The effect file's field tags (docs/internals/effect-file.md): under each
# struct an effect def reaches, each stored field's tag, its name and its
# wire kind, what its bytes are. tools/gen_file.py reads it. A tag is
# numbered within its struct and never reused: a renamed field keeps its
# tag; a field removed, or whose wire kind or default changes, has its tag
# retired ("retired N") and a changed field takes a new one.
