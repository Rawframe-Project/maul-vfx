# The effect file's field tags (docs/internals/effect-file.md): under each
# struct an effect def reaches, each stored field's tag, its name, its wire
# kind (what its bytes are) and, for a field that is not a struct, after
# "=", its default: the hex of the bytes a file would write for it, then
# path=hex for each place whose default differs. tools/gen_file.py reads it
# and writes the defaults into test/file_pins.h, against which the suite
# test_file_defaults checks the default functions. A tag is numbered within
# its struct and never reused: a renamed field keeps its tag; a field
# removed, or whose wire kind or default changes, has its tag retired
# ("retired N") and a changed field takes a new one.
